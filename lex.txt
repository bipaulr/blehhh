LEXICAL ANALYZER IN C

ALGORITHM
1.  Take the source filename as a command-line argument or ask for it in the terminal.
2.  Open the file for reading. If opening fails, print an error and stop.
3.  Read characters from the file one by one until EOF.
4.  If the character is a space, tab or newline, skip it.
5.  If it is a letter or underscore, keep reading letters, digits and underscores into a word. Compare the word
 with the keyword list and print KEYWORD or IDENTIFIER.
6.  If it is a digit, keep reading digits and print NUMBER.
7.  Anything else is printed as a SYMBOL. Report tokens longer than 63 characters.
8.  Check for a read error, close the source file and stop.
