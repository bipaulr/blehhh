LEX: STRINGS WITHOUT THE FIRST FOUR LETTERS OF MY NAME (Paul)

ALGORITHM
1.  Use the substring Paul (the first four letters of the name). Matching ignores letter case.
2.  Print "Enter a string: " and start the Lex scanner.
3.  Rule 1, .*paul.*, matches a whole line containing Paul anywhere. It prints NOT ACCEPTED (Contains Paul).
4.  Rule 2, .+, matches any other non-empty line. It prints ACCEPTED (Does not contain Paul).
5.  On a line with Paul, both rules match the whole line. Lex picks the rule written first, so NOT ACCEPTED wins.
6.  Rule 3 swallows the newline. Continue scanning until EOF.
7.  To use a different name, change paul in rule 1 and in the printed text to the first four letters of that name.
