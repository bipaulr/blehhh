# Only the restricted grammar from the PDF is supported; this is not a full C parser.
# Valid: assignment initialization, comparison, postfix increment, semicolon body.

# Valid: int declaration, assignment update, assignment block body.

# Valid: empty initialization, condition and update.
for(;;);
# Valid: prefix increment, a single statement as the body, and a nested loop.
