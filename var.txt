YACC: VALID VARIABLE NAME

ALGORITHM
1.  Lex file: a letter or underscore returns L, a digit returns D, any other character is passed on as itself.
2.  Yacc grammar: variable = L rest newline, and rest = zero or more of L or D.
3.  So a name must start with a letter or underscore, followed by any letters, digits or underscores.
4.  If the grammar matches, print Valid Variable. If not, yacc calls yyerror, which prints Invalid Variable.
