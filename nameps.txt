PSEUDOCODE: ACCEPT STRINGS WITHOUT THE SUBSTRING "Paul"

BEGIN
    SET matching to case-insensitive
    PRINT "Enter a string: "

    WHILE input remains
        READ a line's characters, excluding its newline

        IF line contains "paul" in any letter case
            PRINT "NOT ACCEPTED (Contains Paul)"
        ELSE IF line is non-empty
            PRINT "ACCEPTED (Does not contain Paul)"
        END IF

        IGNORE the newline
    END WHILE
END

LEX RULE ORDER
    Rule 1: .*paul.* -> PRINT "NOT ACCEPTED (Contains Paul)"
    Rule 2: .+       -> PRINT "ACCEPTED (Does not contain Paul)"
    Rule 3: newline  -> IGNORE

NOTE: When both rules match the entire line, their matched lengths are equal.
Lex chooses the first rule, so a line containing "Paul" is not accepted.
Empty lines produce no output. Paul is the first four letters of the name used here.
