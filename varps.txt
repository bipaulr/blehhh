PSEUDOCODE: VARIABLE-NAME VALIDATION USING LEX AND YACC

FUNCTION NEXT_TOKEN
    READ one character
    IF character is a letter OR an underscore
        RETURN L
    ELSE IF character is a digit
        RETURN D
    ELSE
        RETURN the character itself, or EOF at end of input
    END IF
END FUNCTION

GRAMMAR
    variable = L rest newline
    rest = rest L OR rest D OR empty
END GRAMMAR

BEGIN
    CALL Yacc parser using NEXT_TOKEN and the grammar

    IF tokens match one letter followed by zero or more letters/digits,
       ending with newline
        PRINT "Valid Variable"
        ACCEPT immediately AND STOP successfully
    ELSE
        PRINT "Invalid Variable"
        STOP with parsing failure
    END IF
END

NOTE: One case is checked per run. Spaces, hyphens and other punctuation are
invalid. An underscore counts as a letter, as in C.
