YACC: SYNTAX CHECK OF A FOR STATEMENT

ALGORITHM
1.  Lex: for returns FOR, int returns T, names return ID, numbers return NUM, comparison operators return REL,
 ++ or -- return INC. Other characters pass through.
2.  Yacc: start = forstmt newline, and forstmt = FOR ( init ; cond ; update ) body.
3.  init is ID = expr, or int ID = expr, or empty. cond is expr REL expr, or empty.
4.  update is ID INC (i++, i--), INC ID (++i, --i), ID = expr, or empty.
5.  body is { stmts }, or one stmt, or a lone ;. stmt is ID = expr ; or another forstmt (a nested loop).
6.  expr is simple arithmetic with + - * / and brackets.
7.  If the whole line matches, print Valid FOR statement. Otherwise yyerror prints Invalid FOR statement.
